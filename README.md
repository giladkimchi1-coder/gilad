# יומן אתר בינפלד

אפליקציית ניהול אתר בנייה (Next.js + Supabase). האפיון המלא וההוראות ל-Claude נמצאים ב-[CLAUDE.md](CLAUDE.md).

## הרצה במחשב

```bash
npm run dev
```

ואז לפתוח http://localhost:3000 ולהיכנס עם המייל (קישור כניסה נשלח למייל).

## פקודות

| פקודה | מה היא עושה |
|---|---|
| `npm run dev` | מריץ את האפליקציה במחשב |
| `npm run build` | בונה גרסה לשרת (ובודק שאין שגיאות) |
| `npm run db:migrate` | מעדכן את מבנה מסד הנתונים מ-`supabase/migrations` (בטוח להריץ שוב) |
| `npm run db:import` | טוען את `data/` ו-`assets/` מהאפליקציה הישנה. מוסיף רק מה שחסר |
| `npm run db:import -- --overwrite` | במעבר הסופי: מחליף רשומות קיימות בייצוא העדכני |

המפתחות נמצאים ב-`.env.local`, שלא עולה ל-GitHub.

## איך זה בנוי

- `src/legacy/` – המסכים והלוגיקה, הועברו מהאב-טיפוס `current-app.html` כמו שהם (`app.js`, `markup.ts`),
  ו-`services.ts` שמחבר אותם ל-Supabase.
- `supabase/migrations/0001_init.sql` – הטבלאות, התפקידים וכללי הגישה (RLS). כל הנתונים נשמרים כמסמכי JSON
  לפי נתיב (`projects/kbz/logs/2026-10-26`), ונקראים רק דרך פונקציות `store_*` שבודקות תפקיד ומסתירות
  סכומים ממנהל עבודה ורכש.
- `src/app/blob/[id]` – הגשת תמונות ו-PDF אחרי בדיקת הרשאה. צילומי חשבוניות ושכר רק להנהלה.
- `src/app/api/ai/read` – קריאת תעודות וחשבוניות מתמונה עם Claude (המפתח נשאר בשרת).
- `src/lib/whatsapp.ts` – ממשק השליחה לוואטסאפ. כרגע: כפתור "שתף" לטקסט שאושר בלבד.
